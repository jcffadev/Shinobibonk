# Publicar no GitHub

A fonte única destas instruções é `skills/publicar-github/SKILL.md`, na raiz do projeto. Leia esse arquivo e siga o procedimento completo:

1. Documentação sincronizada.
2. Verificações passando.
3. Conferência de arquivos sensíveis.
4. Commit em português.
5. `pull --rebase` seguido de push para `origin main`, sem force.
6. Relatório com hash e link do commit.

Git neste PC: `& "C:\Program Files\Git\cmd\git.exe"` (não está no PATH).
